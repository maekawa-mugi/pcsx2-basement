# PCSX2 Basement
PCSX2 Basement is a project that incorporates a custom Full TLB implementation (with recompiler support) and AVX-512 support, alongside cherry-picked implementations of Softfloat and Parallel-GS.

You are free to use AI with this project, but please ensure you do not cause issues for the upstream project or other forks.

## Guidelines for Contributions
I am strongly interested in the PS2 as a computer system; therefore, I broadly welcome pull requests aimed at its reproduction - whether or not they utilize AI - as long as they offer improvements.
